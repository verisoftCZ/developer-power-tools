# Code of conduct

Treat contributors and users with respect. Welcome people with different backgrounds, experience levels and accessibility needs. Discuss code and ideas constructively; give specific feedback and assume questions are asked in good faith.

Harassment, discriminatory language, threats, sexualized conduct, personal attacks and publishing another person's private information are not acceptable in issues, pull requests or other project spaces. Do not post secrets or personal data as test examples.

Maintainers may edit or remove harmful content, close disruptive discussions and restrict participation. Decisions should be proportionate and explain the behavior that needs to change when appropriate. Good-faith criticism and technical disagreement are welcome.

Report concerns privately to repository maintainers through GitHub. If a concern involves a vulnerability or exposed private data, follow [SECURITY.md](SECURITY.md). Maintainers should protect the reporter's identity and share details only as needed to address the concern. No response-time guarantee is made.
