# Operation guide

| Area        | Operations                                                                                                                                                                               |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Conversion  | Text → Bytes (UTF-8), Bytes → Text (strict UTF-8 by default)                                                                                                                             |
| Encoding    | Base64 → Text, Text → Base64, raw-byte Base64 encode/decode (standard / URL alphabet, strict / whitespace-tolerant decode), Hex encode/decode, URL encode/decode (whole URL / component) |
| JSON        | Parse, unescape, decode escaped JSON fields, escape whole JSON or selected fields, pretty print, minify, nested JSON parsing by RFC 6901 pointer or bounded recursive traversal          |
| Inspection  | JWT decode (optional Bearer prefix; **signature not verified**), SHA-256, Unix timestamp, Date → UTC / Timezone                                                                          |
| YAML        | YAML → JSON, JSON → YAML, direct YAML tree and graph inspection                                                                                                                          |
| Generation  | Generate GUID (random UUID v4), optional count, uppercase and braces                                                                                                                     |
| Compression | Gzip compress/decompress with output size limits                                                                                                                                         |

Conversions between text, bytes and JSON are explicit. Use **Text → Base64** and **Base64 → Text** for one-step UTF-8 conversions; invalid UTF-8 decoding fails. For raw bytes, use **From Base64** / **To Base64** with the explicit byte conversion operations. For pretty printing text JSON, add **JSON Parse**, then **JSON Pretty Print**.

**JSON Unescape** decodes one layer of JSON string escaping: `{\"id\":42}` becomes `{"id":42}`. It accepts a complete quoted JSON string or its escaped contents; **Input format** defaults to auto-detection. Escapes such as `\n`, `\t`, `\\`, and `\u0041` are decoded using JSON rules. Invalid escapes fail explicitly. The result is text; append **JSON Parse** for tree/graph inspection. For escaped strings inside an already parsed object, use **Parse Nested JSON** with a JSON Pointer.

**Decode Escaped JSON Fields** accepts a pasted JSON document or parsed JSON. It recursively converts strings containing objects/arrays into structured JSON, including entries in arrays, while preserving existing objects and ordinary strings, numbers, booleans and nulls. For example, `{"Metadata":"{\"a\":{}}","Other":{"x":"value"}}` becomes `{"Metadata":{"a":{}},"Other":{"x":"value"}}`. Malformed JSON-looking fields fail with their pointer; the operation is atomic and bounded by depth and visited-value limits. It does not interpret plain strings such as dates, numeric identifiers or `"true"` as typed values.

**JSON → Escaped JSON** accepts pasted or parsed JSON. Default **whole document** mode returns a quoted JSON string. To reverse the mixed-field example, choose **selected fields** and enter `/Metadata, /Data` in **JSON Pointers, comma separated**. Only those object/array fields are stringified; other fields stay structured. Pointer escapes `~1` for `/` and `~0` for `~` are supported. Missing, overlapping or scalar paths fail. The result is JSON text; append JSON Parse if you need a structured result.

**Generate GUID** ignores input and creates UUID v4 identifiers using Node's cryptographic random generator. Defaults to one lowercase dashed GUID; choose a count (up to 1,000), uppercase or braces. Each execution, including auto-run, generates fresh values.

**Date → UTC / Timezone** defaults to **Europe/Prague** and Czech **dd.MM.yyyy HH:mm:ss** output (nonzero milliseconds are retained). Example: `2025-08-19T10:00:00Z` becomes `19.08.2025 12:00:00`. Choose **ISO 8601** under **Output format** for an ISO string with a numeric zone offset, or `Z` when Output timezone is UTC. Auto-detection supports ISO dates/date-times, `dd.MM.yyyy` with optional time, unambiguous slash dates, and 10/13-digit Unix seconds/milliseconds. Choose a format for ambiguous slash dates; custom formats support `yyyy`, `MM`, `dd`, `HH`, `mm`, `ss`, `SSS`, literal `T`, spaces and punctuation. Unzoned input still uses **Source timezone**, default UTC; explicit offsets take precedence. Invalid dates/DST gaps fail; repeated DST times require an earlier/later choice or explicit offset. Parsing is independent of the machine timezone/locale. Rules come from the host's ICU database. Years 0001–9999 and millisecond precision are supported. Existing recipes retain their saved output timezone; select Europe/Prague in an existing card if it saved UTC.

**YAML → JSON** parses a single YAML 1.2 document into structured JSON. **JSON → YAML** accepts pasted or parsed JSON and emits YAML with 2/4-space indentation. Select **Graph** directly on YAML text output (or pasted YAML with an empty recipe); no JSON conversion step is needed. YAML is also supported in the tree tab, currently labelled JSON tree. Zoom, pan, collapse, search, fit and node limits work the same way. Only JSON-compatible types are allowed: unsupported tags, duplicate/complex keys, cycles, excessive aliases, oversized integers, non-finite numbers and multiple documents fail explicitly. Comments and source formatting are not preserved. Conversion is bounded to 64 levels/100,000 values. The parser is bundled locally; no service or network access is needed.

**JWT Inspect** accepts either a bare token or `Bearer <token>` (case-insensitive prefix, optional surrounding whitespace). It only decodes the header and payload; signatures are **not verified**.
